# Cryptocurrency Price Tracker

## Project Description

Cryptocurrency Price Tracker is a Python-based web scraping project that collects the latest cryptocurrency price details from CoinMarketCap.

The project uses Selenium to automatically collect the top 10 cryptocurrencies and stores the collected data in a CSV file.

## Features

- Collects the top 10 cryptocurrencies
- Scrapes cryptocurrency price details
- Uses Selenium for web scraping
- Uses Pandas for data processing
- Saves the data in CSV format
- Easy to run and update

## Technologies Used

- Python
- Selenium
- Pandas
- WebDriver Manager
- Chrome WebDriver

## Project Files

- crypto_tracker.py – Python program used for web scraping
- crypto_prices.csv – Stores the collected cryptocurrency data
- README.md – Project documentation

## How It Works

1. The program opens CoinMarketCap using Selenium.
2. It collects the top 10 cryptocurrency details.
3. The collected data is processed using Pandas.
4. The data is saved in a CSV file.
5. The CSV file can be used for further analysis.

## How to Run

Install the required libraries:

pip install selenium pandas webdriver-manager

Run the Python program:

python crypto_tracker.py

The output will be stored in:

crypto_prices.csv
